# Environment Records

Recorded environments remain alongside their applicable stages and historical run configs. `evidence_index/ENVIRONMENT_RECORD_INDEX.csv` lists their file/hash identities. Exact environment details are sourced from those records, never a newly collected pip freeze. Import names are static dependency inventory, not proof of successful installation or compatible package resolution.

Original July/August archives include requirements files and retained per-run environment.json. B1 analysis, B2 GPU evaluation/CPU statistics, OriginalCore, P3/P4, P5/P6 and routeB have distinct records. FULL/ZERO/P1/P2 lack a separately complete lockfile in this collection; effective configs, initialization records and the preserved reports retain the versions actually recorded. Missing package versions remain unrecorded. No environment was installed or upgraded.

Use the unmodified package-specific third-party licenses from legitimate upstream distributions. The local-release notices document known dependencies but do not relicense this assembled candidate.
