# R5.2 figure sources

`render_figure3_r52.py` redraws the new Figure3A/B from saved numerical coordinates only. Each panel is created independently and then combined; no inference or interval estimation is performed. Figure3A preserves the R5.1 values. Figure3B derives from the completed matching contrast tables and actual per-run differences.

The original architecture PPTX and unchanged Figures1/2/4/S1–S9 sources are retained as historical editable assets. The older `render_statistical_figures.py` is the R5.1 historical script; it is not the current Figure3 production entry. Do not replace the new figure by running that old entry. No font files are distributed.

Figure3 PNG/TIFF/PDF is the complete publication figure. Figure3A/B SVG/PDF files are separate vector-editable panels. All independent images in Submission_Files correspond to the embedded versions in the accompanying manuscript/supplement.
